# SOP-305: HPLC System Suitability and Calibration

**Revision:** 5 | **Effective Date:** 2025-06-01 | **Author:** Dr. Raj Patel  
**Department:** Analytical Chemistry | **Classification:** GxP-Critical

## 1. Purpose

Establishes system suitability requirements for HPLC instruments used in quantitative analysis.

## 2. Scope

All HPLC systems in QC and R&D laboratories performing regulated testing.

## 3. System Suitability Requirements

### 3.1 Daily Verification

Before any analytical run, perform system suitability with reference standard.

### 3.2 Acceptance Criteria

| Parameter | Acceptable Range | Unit |
|---|---|---|
| Retention time RSD | ≤ 1.0 | % |
| Peak area RSD | ≤ 2.0 | % |
| USP tailing factor | 0.8 – 1.5 | - |
| USP resolution (adjacent) | ≥ 2.0 | - |
| Theoretical plates | ≥ 2000 | - |
| System suitability injections | ≥ 5 | count |

### 3.3 Failure Actions

If system suitability fails:

1. Do NOT proceed with sample analysis.
2. Investigate root cause (mobile phase, column condition, detector).
3. Document failure in HPLC Logbook.
4. Re-run suitability after corrective action.
5. If failure persists after 3 attempts, escalate to Lab Supervisor.

## 4. Calibration Schedule

| Component | Frequency | Tolerance |
|---|---|---|
| UV detector | Quarterly | ± 1 nm |
| Autosampler volume | Monthly | ± 2% |
| Column oven | Semi-annual | ± 1.0°C |
| Flow rate | Monthly | ± 2% |

## 5. Records

Maintain all calibration records for minimum 7 years per regulatory requirements.
